# Showcase

Design images for both mods. `in_game` folders are real Minecraft screenshots from the scripted client tests;
`design_renders` are the generator previews used while designing the models.

- `obsolete/in_game_armor` – every armor set on the redesigned OBSOLETE-style frame (standing + walking), bare frame
- `obsolete/in_game_weapons` – all weapons aimed / at rest, before-vs-after sheet, item icons
- `obsolete/in_game_flight` – flight booster, VTOL wings, drone lifter in flight; pilot camera views
- `obsolete/design_renders` – frame before/after, each armor set, flight modules
- `titan_combat/in_game` – fleet: carrier deck, LCAC, C-130 airdrop, repair truck, camo, assembly bay
- `titan_combat/design_renders` – Chinook, V-22, APC, mobile suit trailer, carrier, C-130, LCAC, repair truck
